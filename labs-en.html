How to read these tables#

All laboratory values from the records are collected in tables by date: dates run across the columns from left to right, parameters down the rows. Values outside the reference range of the laboratory that ran the test are shown in red; the arrow shows the direction: ↑ — above normal, ↓ — below. A dash means the parameter was not measured that day or is not in the records.

⚠️ Different laboratories use different analysers and different reference ranges. The tables are therefore split by laboratory: the LoVet in-house lab, IDEXX, and the 24-hour clinic TENVET. Numbers can only be compared directly within one table. The summary table in section 1 is for an overview, not for exact comparison.

Details of each test are in the entry for that date in the full chronology.
