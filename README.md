# Варя — полная медицинская хронология

Сведённая история болезни кошки Вари: онкология молочной железы, операции,
химиотерапия, лабораторная динамика, офтальмология и кардиология за период
**24.06.2025 – 07.09.2026**.

Отчёт составлен владелицей по фотографиям документов из нескольких клиник
и лабораторий (LoVet, ALVET, Retina, ALPHAVET, IDEXX, ALAB) и предназначен
для передачи новому врачу или консультирующему специалисту.

> Документ не заменяет осмотр и заключение ветеринарного врача.

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `final_report.md` | Источник. Всё содержательное правится **только здесь**. |
| `index.html` | Собранная HTML-версия для чтения и печати. Файл самодостаточный. |
| `build.js` | Сборщик: Markdown → HTML. |
| `src/style.css`, `src/app.js` | Оформление и поведение страницы, встраиваются в `index.html` при сборке. |

## Чтение

Откройте `index.html` в браузере — оглавление с подсветкой текущего раздела,
светлая и тёмная темы, печать в PDF через «Печать» (`Cmd/Ctrl + P`).

## Сборка после правок

```bash
npm install   # один раз
npm run build # final_report.md → index.html
```

Сборщик размечает структуру отчёта: нумерованные разделы, годовые срезы
хронологии, датированные записи визитов, врезки ⚠️ с расхождениями между
документами и лабораторные таблицы с закреплённым первым столбцом.
Изменять `index.html` вручную не нужно — он перезаписывается при каждой сборке.
